# Anno 1800 18.4 物资快捷键（v3.7）。保存文件后，运行中的修改器会自动重载，无需重启。
#
# 格式：快捷键=物资GUID|显示名称|可选标记
#   左侧：0..9（= Ctrl+数字）、Ctrl+Shift+数字、Ctrl+Alt+数字、Ctrl+Shift+Alt+数字，共 40 个位置。
#   右侧：物资 GUID + 显示名称（名称只用于窗口提示，可以随便改）+ 可选标记。
#   一个快捷键和一个 GUID 各只能出现一次；删掉一行就取消该键；改错时旧键位继续有效。
# 固定键位（不受本文件影响）：Ctrl+1 造船、Ctrl+- 影响力 +100、Ctrl+Alt+- 全部物资拉满并锁定、Ctrl+F12 恢复并退出。
#
# 本表所有物资键都带 |toggle，做成开关（全部 39 种一样）：
#   按一次 → 各岛拉到当前上限；再按一次 → 各岛清空为 0；如此往复。
#   判断依据是当前库存（所有岛都已在上限 → 这次清空，否则 → 这次拉满），所以不会失步。
#   清空同样会记录"修改前的数量"，Ctrl+F12 仍可整体还原。
#   注意：Ctrl+Alt+- 全部物资锁定开启时，被清空的物资会在 0.25 秒内被锁定补回上限。
#   想让某个键只填一次（不参与清零），把那一行尾的 |toggle 删掉即可，保存后立刻生效。
#
# 本表全部 39 个 GUID 已用本机游戏文件 maindata\data0.rda 核对过（见 物资编号参考.txt），
#   旧世界/海角物资（仓库分类标记 15）与 新世界/DLC 物资（分类标记 1）都支持。
# 游戏窗口必须在最前面时按键。
# 新岛：游戏中保存一次或等自动存档即可自动识别，不用重启修改器。
#
# 常用但本表没有的位置：原木 wood = 120008（40 个位置已全部占用，
#   想加原木就把某一行换成 120008|原木|toggle，例如 Ctrl+Shift+Alt+2=120008|原木|toggle）。
